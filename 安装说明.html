WhatsApp 助手 · 免费本地版 2.3.8

聊天备份、批量发送、联系人管理和屏幕隐私保护，无订阅或激活码。

  1. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
  2. 开启开发者模式，选择“加载已解压的扩展程序”。
  3. 选择 WA-Assistant-Free 文件夹，确认其中直接包含 manifest.json。
  4. 停用旧备份插件与 Easy Sender，避免相互干扰。
  5. 登录 WhatsApp Web 并刷新，点击右侧绿色时钟打开面板。
  6. 选择“聊天备份 / 批量发送 / 联系人 / 隐私保护”。发送前先生成预览并核对。

当前版本已通过模拟与独立浏览器界面测试，实际 WhatsApp 接口兼容性尚需实测。用户创建的定时与后台任务会在浏览器运行、原账号连接后执行；发送结果不确定时暂停核对。
