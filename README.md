# WhatsApp 助手 · 免费本地版 2.3.8

运行在 **WhatsApp Web** 上的 Chrome / Edge 浏览器扩展，提供聊天备份、语音导出、快捷回复、联系人整理、批量发送和屏幕隐私保护。它是独立第三方工具，并非 WhatsApp 或 Meta 官方产品。

## 下载与安装

1. 从 [Releases 发布页](https://github.com/liushuaiye2602141602-cmyk/WA-Assistant-Free/releases/latest) 下载插件 ZIP，并解压到固定目录。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择**直接包含 `manifest.json` 的文件夹**。发布附件中为 `WA-Assistant-Free`；GitHub 源码 ZIP 的解压目录名可能不同。
5. 停用可能冲突的 WhatsApp 扩展，打开 [WhatsApp Web](https://web.whatsapp.com/)，登录后刷新。
6. 点击页面右侧绿色时钟，或插件弹窗中的“打开助手面板”。

更新时将新版文件放回原加载目录，在扩展管理页重新加载，再刷新 WhatsApp Web。核对版本为 **2.3.8**；不要先卸载，以免丢失本地数据。

详细步骤见 [使用说明](使用说明.md)。

## 主要功能

| 功能 | 可以做什么 | 需要注意 |
| --- | --- | --- |
| 聊天备份 | 导出 ZIP、HTML、Markdown、TXT、JSON，并按需保存媒体 | 仅导出接口可读取的记录与可下载媒体，不能保证完整历史 |
| 语音导出 | ZIP 保存音频；单独 HTML 可内嵌播放 | MD/TXT/JSON 单独导出不包含音频文件本体 |
| 快捷回复 | 管理常用回复，填入输入框并保留草稿 | 用户手动发送，没有关键词规则自动回复 |
| 联系人整理 | 分类读取、多群成员读取、号码/ID 去重、CSV/XLSX 导出 | 标签、号码和群信息受账号及接口可见性限制 |
| 批量发送 | 导入名单、字段替换、附件、录音、按钮、预览、定时与任务报告 | 收件人须同意接收；接口提交不等于送达或已读 |
| 自动退订 | 监听个人聊天关键词，按账号排除后续收件人 | 发送前补查最近 30 条消息，不能保证覆盖更早或未同步记录 |
| 屏幕隐私 | 模糊消息、名称、头像、媒体等页面内容 | 只改变本机显示，不提供加密 |

导入号码需位于第一列，推荐表头为 `phone,name,company`；XLSX 读取第一个工作表，文件不超过 20 MB。附件单个不超过 16 MB、总计不超过 32 MB；录音最长两分钟。

首次使用建议先导出一份 ZIP 备份，再以少量已获同意的收件人测试发送。发送前生成预览并核对；删除聊天不是撤回，可能清除已有本机历史。

## 2.3.8 更新重点

- 修复弹窗操作消息被后台忽略的问题，限定支持的指令，并完善无回复和异常提示。
- 防止导入表格的 `id` 字段覆盖规范化的收件人 ID。
- 加强 XLSX 文件边界、解压大小和单元格坐标检查。
- 在创建及执行发送任务前校验附件结构。
- 增加聊天列表键盘选择及焦点保持，补充弹窗和 XLSX 测试。

本仓库另保留可切换中英文的免责声明和弹窗入口。

## 数据与运行条件

设置、快捷回复、任务、附件、报告及退订名单等保存在浏览器扩展本地，导出文件下载到电脑。WhatsApp 操作和媒体下载仍需联网，“本地版”不代表完全离线运行。

浏览器退出或电脑休眠期间不能执行发送。后台任务需要浏览器运行、任务绑定账号连接且页面接口就绪；定时可能延后。卸载扩展、清理浏览器数据或更换配置可能丢失本地数据，目前没有统一设置备份或一键数据清理。

## 验证与限制

项目包含八套原包测试及一套免责声明语言切换测试，覆盖模拟接口、任务恢复、媒体导出、快捷回复、界面、弹窗及 XLSX。浏览器测试使用 Edge，测试代码中的 Playwright 路径依赖原环境，换电脑需调整。

这些测试不等于真实 WhatsApp 账号验证。发送、删除、按钮消息、媒体下载及群回执的线上兼容性仍需小范围确认；WhatsApp 改版可能导致功能失效。页面事件桥接的安全边界、大文件内存占用和本地数据清理仍有改进空间。

当前没有 CRM 集成、多账号并发、关键词规则自动回复、联系人搜索或聊天按日期筛选。
