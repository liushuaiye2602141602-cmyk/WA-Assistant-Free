## 安装与更新

Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。开启开发者模式，加载已解压的扩展程序，选择 WA-Assistant-Free 文件夹。停用旧备份扩展和 Easy Sender，登录 WhatsApp Web 并刷新，点击右侧绿色时钟打开面板。

从 2.0 升级：在扩展管理页刷新此扩展，确认新增的 alarms 权限，并刷新 WhatsApp 页面。旧模板保留；旧版报告不自动转换成任务，避免意外重发。

## 新增功能

- 录音：允许使用麦克风，录音结束后可试听，作为语音附件发送。最长两分钟，结束后释放麦克风。
- 按钮：每行“文字 | 类型 | 内容”；类型为 url、phone、reply、copy，最多三行。回复按钮不能与网址或电话混用。按钮是否显示取决于 WhatsApp 兼容性，不支持时不会自动降级重发。
- 送达和已读：监听回执并可补查；一位收件人的所有本次消息满足条件才计数。群组不会把一个成员已读算作全群已读。对方关闭已读回执时不能保证查询到。
- 自动退订：完整匹配“退订”“取消订阅”“stop”“unsubscribe”“不要再发”等关键词，忽略大小写及末尾常见标点。按账号保存排除名单，后续自动跳过，可调整关键词、关闭监听或明确允许再次联系。
- 实际发送时间：每位收件人发送时追加本机时间；报告记录提交时间。
- 多群成员：Ctrl 多选群，合并成员并按可解析手机号或原始 ID 去重；支持排除管理员。
- 活跃度：根据可见的最近上线时间和收到消息判断观察窗口内有无活动证据。数据隐藏时显示未知，不代表不活跃；支持导出报告。
- 自动删除：默认关闭，可选仅删除本次消息或整个聊天，必须勾选确认删除范围。删除不是撤回，对方仍可看到消息；整个聊天包含已有历史，建议先备份。只有本位收件人全部提交完成才执行删除，删除失败独立报告。
- 定时：填写未来时间，留空立即执行。任务和附件保存到扩展本地，绑定创建时的账号。
- 页面关闭后的执行：浏览器运行时，待执行任务会重新打开非激活 WhatsApp 标签页，等待原账号连接。

## 保留功能与使用步骤

聊天备份保留 ZIP / HTML / Markdown / TXT / JSON、媒体下载、连接诊断。发送保留 CSV / XLSX 导入、占位符、附件、模板、随机间隔、预览、暂停、停止和报告；联系人保留分类、Business 标签、CSV / Excel 导出；隐私保留六类模糊开关。

先读取号码或导入文件，再输入消息，例如“你好 {{name}}，这是 {{company}} 的产品信息”。添加附件或录音、按钮等选项，生成预览，确认收件人同意接收后点击开始发送。自定义占位符必须对应表头；XLSX 读取首个工作表。

在任务下拉框中选择已有任务，可暂停、恢复、停止或查询回执。失败项先生成重试预览，再人工启动；结果不确定或部分提交的项不会自动重试。

## 恢复与限制

浏览器退出、电脑休眠时无法执行。恢复运行后，在绑定账号连接就绪时继续；闹钟和后台节流可能导致延后，不能承诺精确到秒。

发送前保存状态，每条文本或附件提交后保存消息 ID。中断、超时、部分发送或无法确认结果时，标记“不确定”并暂停。核对后点击恢复，只继续其余未发送项，不重发不确定项。暂停在当前提交后生效；停止不能撤回正在提交或已提交的消息。

自动退订仅处理个人聊天，发送前补查最近 30 条消息，不能保证找回未同步或更早的离线退订。上线时间、已读和按钮受隐私设置及 WhatsApp 版本限制。删除后的本地消息可能不能再次补查回执，群组删除行为也受 WhatsApp 限制。

附件单个不超过 16 MB、总计不超过 32 MB，这是内存保护限制。XLSX 不支持老 .xls、加密、宏或公式计算；号码建议设为文本。模板、任务、附件、报告和退订名单保存在扩展本地，不上传原厂营销服务器，WhatsApp 操作仍需联网。

没有接入用户排除的原厂线索库、CRM、协议号群发、多号并发。

## 2.2.1：聊天语音导出完善

原版已经识别 audio / ptt 消息；本次完善实际导出：

- 媒体开关明确包含语音/音频，默认勾选。
- ZIP 的 media/ 保存音频原始文件，chat.html 可播放并下载，chat.md 提供相对链接。
- 单独 HTML 内嵌音频，可离线播放并下载；MD、TXT、JSON 单独导出仅保留描述和元数据，不包含音频本体。
- 根据媒体 MIME 保留正确扩展名，如 OGG/Opus、MP3、M4A、WAV、WebM；同名附件先去重，再生成文档链接，避免覆盖或错链。
- 页面与内容脚本之间明确传输音频字节和 MIME；记录语音类型、时长、实际文件名及下载失败信息。
- 下载失败不生成无效播放链接，导出日志显示成功音频数与失败音频数，ZIP 附带“媒体下载失败.txt”。WhatsApp 中已失效、不可下载的媒体无法补回。
- 新增 tests/media.test.cjs：验证原始字节、格式命名、同名文件、失败提示、ZIP、元数据及真实浏览器对测试音频的解码；没有下载真实聊天或语音。

使用建议：勾选“包含图片、视频、语音/音频及文件”，选择 ZIP 或单独 HTML。解压 ZIP 后打开 chat.html 播放语音。


## 2.2.1：鼠标悬浮快捷回复

鼠标移到对方的聊天消息气泡旁，会出现“快捷回复”按钮。点击按钮选择常用回复语，内容填入聊天输入框，保留已有草稿；由你确认发送，不会自动发送。

内置中文问候、英文问候、稍后回复、询问需求、报价和感谢等示例。点击悬浮菜单的“管理回复语”，或助手面板顶部的“回复语设置”，可添加、编辑、删除回复语。支持多行文字，保存在浏览器本地。关闭悬浮功能后仍可从面板进入设置并重新开启。

只在对方消息上显示，不在自己的消息旁显示；切换聊天或原消息被移除后关闭菜单，避免误填到其他会话。若 WhatsApp 页面改版导致输入框无法识别，可点击“复制”再手动粘贴。

新增 tests/quick-replies.test.cjs，覆盖鼠标悬浮、保留草稿、只填入不发送、本地设置、开关、切换聊天保护及窄屏定位。真实 WhatsApp 的消息选择器和输入框仍需实机确认。
